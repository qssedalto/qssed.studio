AERTEX Bridge

macOS · Apple Silicon & Intel

本地 LaTeX 编译桥接服务 / Local LaTeX compilation bridge

此安装包会安装后台 Bridge 服务和带图标的状态管理 App，登录后自动启动后台服务。 The installer includes a background LaunchAgent and a status manager in Applications.

需要单独安装 MacTeX 或 TeX Live 才能编译 PDF。 MacTeX / TeX Live is required separately to compile PDFs.

This preview package is unsigned and not notarized. It does not disable Gatekeeper or modify macOS security settings.
